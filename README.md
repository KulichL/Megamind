# Memory Symbol Game 🎮

Simple Java Swing memory game where the player must memorize symbols and find them in a grid.

## 📌 Description
The game shows 3 random symbols that the player must memorize.  
After a short time, the symbols disappear and the player must find them in a 3x3 grid across 3 rounds.

## 🧠 Features
- Multiple windows (Start, Memory, Game Rounds)
- Countdown timer for memorization phase
- Timer for each round
- Score tracking (0–3)
- Object-Oriented Programming (OOP)
- Abstract classes and inheritance
- MVC-like structure (GameController handles logic)
- Exception handling for stability

## 🛠️ Technologies
- Java
- Swing (GUI)
- AWT
- Collections (ArrayList, List)

## ▶️ How to run
1. Open project in IntelliJ IDEA (or other Java IDE)
2. Make sure JDK is installed (Java 8+ recommended)
3. Run the `Main` class

## 🎯 Objective
Find all correct symbols from memory in the correct rounds and get the highest score (max 3).
